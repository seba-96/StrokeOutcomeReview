# Scripts to reproduce findings from a review and meta-analysis on post-stroke outcome prediction 

### Title: "Do neuroimaging features improve the prediction of functional outcome after stroke? A systematic review and meta-analysis" 
### Authors: S. Cinetto, AL. Bisogno, L. Pini and M. Corbetta
### Status: Submitted

To replicate the results install the required python libraries and run: python3 /src/review/main_analysis.py
